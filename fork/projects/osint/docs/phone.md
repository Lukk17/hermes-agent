# Phone OSINT

## Free

#### PhoneInfoga
Open source phone number OSINT. Carrier detection, location approximation, reputation score, social media checks. CLI tool.
https://github.com/sundowndev/phoneinfoga

---

#### Truecaller
Phone number identification. Who called, spam check, name and address lookup. Free with account. Large global database.
https://www.truecaller.com

---

#### NumVerify
Phone number validation and geolocation. Free tier with basic info. API available.
https://numverify.com

---

#### OSINT Industries (Free Tier)
Limited free phone OSINT. Shows basic carrier info, some social links. Better data with paid tier.
https://www.osint.industries

---

#### Google
Search phone number directly: `"+48 XXX XXX XXX"`, `"XXX-XXX-XXXX"`, combine with target name for better results.
https://www.google.com

---

#### WhatsApp
Search phone number in WhatsApp to get profile photo, status, last seen (if privacy settings allow).
https://web.whatsapp.com

---

#### Signal
Similar to WhatsApp — check if number is registered and get profile info.
https://signal.org

---

#### Tinder
Phone number can sometimes reveal Tinder profile if connected.
https://www.tinder.com

---
