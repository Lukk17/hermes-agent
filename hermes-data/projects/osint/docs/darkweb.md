# Dark Web & Deep Web OSINT

## Free

#### HaveIBeenPwned
Check if email in known data breaches. Shows breach names, dates, data types. Free.
https://haveibeenpwned.com

---

#### IntelX
Search across leaks, paste sites, dark web by email, domain, IP, PESEL, name. Powerful free tier.
https://intelx.io

---

#### BreachDirectory
Check if email in breaches. Free tier shows first few characters of leaked passwords.
https://breachdirectory.org

---

#### LeakCheck
Free tier — Check if email/username in known leaks. Shows breach names and data types.
https://leakcheck.io

---

#### GhostProject
Free — Search emails in breach data. Shows password if found.
https://ghostproject.fr

---

#### Google
Dark/deep web search via Google: `site:pastebin.com "target"`, `site:ghostbin.co "target"`, `"target" inurl:onion`
https://www.google.com

---

#### Onion Link Search Engines
Search for .onion sites: Torch (`http://xmrh57fwfczwerue.onion`), notEvil (`http://hss3uro2hsxfogfp.onion`), Ahmia (`http://msydqstlz2kzerdg.onion`)
(Access requires Tor Browser)
