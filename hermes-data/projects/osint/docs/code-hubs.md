# Code & Developer Hubs OSINT

## Free

#### GitHub
Code repositories, commit history, contributor names, company affiliations in profiles, README files, organizations. Search: `site:github.com "target"`, `user:target`, `org:companyname`.
https://github.com

---

#### GitLab
Similar to GitHub. Some companies prefer GitLab. Search by username, group, project.
https://gitlab.com

---

#### Bitbucket
Atlassian code hosting. Mercurial and Git repos. Smaller than GitHub but still useful.
https://bitbucket.org

---

#### npm (Node Package Manager)
Published Node.js packages. Maintainer info, company email patterns, download stats, dependencies.
https://www.npmjs.com

---

#### PyPI (Python Package Index)
Published Python packages. Maintainer emails (often), project descriptions, dependencies.
https://pypi.org

---

#### Maven Central / Java
Maven Central Repository. Published JAR files, group IDs, artifact descriptions.
https://mvnrepository.com

---

#### Docker Hub
Docker container images. Image names, descriptions, maintainer info, build history, tags.
https://hub.docker.com

---

#### Quarkus
Java framework packages, but also general package search across multiple ecosystems.
https://registry.access.redhat.com

---

#### Packagist (PHP/Composer)
PHP packages. Maintainer names, company associations, dependency info.
https://packagist.org

---

#### RubyGems
Published Ruby gems. Author info, project descriptions, download counts.
https://rubygems.org

---

#### crates.io (Rust)
Published Rust crates. Maintainer info, version history, dependencies.
https://crates.io

---

#### NuGet (.NET)
.NET packages. Maintainer names, package descriptions.
https://nuget.org

---

#### WordPress Plugins
WordPress plugin directory. Plugin authors, support forums, version history.
https://wordpress.org/plugins

---

#### Blogger / Blogspot
Blogspot blogs. Often used for personal blogs linked from social profiles.
https://www.blogspot.com

---

#### Medium
Articles and posts. Author profiles, publication pages, employer info sometimes listed.
https://medium.com

---

#### Dev.to
Developer community posts. User profiles with social links, GitHub/Twitter connections.
https://dev.to

---

#### Stack Overflow
Q&A profiles. Location, employer, reputation, answers about specific technologies.
https://stackoverflow.com

---

#### GitHub Gist
Code snippets and notes. Often contains configs, API keys (accidentally exposed), personal notes.
https://gist.github.com

---

#### Hacker News
Y Combinator discussion platform. User profiles, karma, posting history.
https://news.ycombinator.com

---

#### Product Hunt
Startup product launches. Founder names, company affiliations, launch dates.
https://producthunt.com

---

#### Thingiverse
3D printable designs. User profiles, upload history, location data in some profiles.
https://thingiverse.com

---

#### Printables
3D model sharing (Prusa). User profiles, makes, download history.
https://www.printables.com

---

#### Instructables
DIY project tutorials. Author profiles, location, project history.
https://www.instructables.com

---

#### Hackaday
Electronics and hardware projects. Author profiles, schematics, project logs.
https://hackaday.io

---

#### GrabCAD
3D CAD model sharing. Engineer profiles, company affiliations, model downloads.
https://grabcad.com

---

#### Sketchfab
3D model viewer/platform. User profiles, model descriptions, likes/collects.
https://sketchfab.com

---

#### Codeberg
Open source Git hosting (Gitea). Similar to GitHub but European/privacy-focused.
https://codeberg.org

---

#### SourceForge
Historical code hosting. Project releases, developer info, download stats.
https://sourceforge.net

---

#### GitHub Organizations
Companies often have GitHub Organization accounts. List of employees, repos, activity.
https://github.com

---

## Paid

#### GitHub (Advanced Search / API)
Paid plans give higher rate limits on GitHub API. Useful for large-scale repo analysis.
https://github.com

---

#### GHTorrent
Historical GitHub event data. Not real-time but useful for academic/research analysis of GitHub history.
https://ghtorrent.org

---

#### GH Torrent
Historical GitHub archive data. Large dataset downloads for offline analysis.
https://ghtorrent.org

---

#### SourceGraph
Universal code search across all repos. Enterprise version can index private code. Pricing on request.
https://sourcegraph.com
